## 步骤

### 1. 扫描高危模块列表

扫描 `{working_dir}/docker_output/` 目录，列出所有子目录（每个子目录代表一个高危模块）。

### 2. 写入总结报告

将以下内容写入 `{summary_path}`：

- 分析状态
- 识别出的高危模块数量
- 每个模块的名称、路径和简要说明

### 3. 为每个高危模块生成任务文件 ★ 关键：一对多扇出

遍历 `{working_dir}/docker_output/` 下的每个子目录，为每个高危模块在 `{results_dir}/` 下创建一个独立的任务文件。

命名规则：`result_001.md`, `result_002.md`, ... （按子目录名排序编号）

每个文件的内容必须严格遵循以下格式：

```markdown
# 反编译优化任务

## 输入
- 输入文件夹: {working_dir}/docker_output/<模块子目录名>
- 模块名称: <模块名称>
- 内容描述: 高危二进制模块文件

## 任务说明
对该高危模块进行反编译和反编译结果优化，生成可读性良好的反编译源码。
将优化后的反编译源码输出到输出文件夹中。
```

> **重要**:
> - 每个 `result_NNN.md` 对应一个高危模块，将独立传递给下一阶段处理（扇出）
> - 路径必须使用绝对路径
> - 模块数量 = 生成的 result 文件数量
