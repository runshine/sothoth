- 每个 EXPORT 终点的跟入情况和发现

#### 1.4 关键发现验证

|--------------|---------|------|---------|
| ★ 发现描述 | 已验证/未验证 | 确认/否定 | result_XXX.md |

### 2. `results/` — 独立漏洞报告

- 命名：`result_001.md`, `result_002.md`, ...
- 每个必须包含：位置、CWE、严重性、置信度、代码片段、攻击路径、触发条件、影响

### 3. 自检

在输出前逐项确认：
- [ ] summary.md 包含全部 7 个章节
- [ ] 数据流的每个 EXPORT 终点在覆盖度表中有记录
- [ ] 数据流的 ★ 关键发现全部有验证结论
- [ ] 每个漏洞报告有 ≥5 行代码片段
- [ ] 每个漏洞有从 INPUT 到危险操作的完整路径
