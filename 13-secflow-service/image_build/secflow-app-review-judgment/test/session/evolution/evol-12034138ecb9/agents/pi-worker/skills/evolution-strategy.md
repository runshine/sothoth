# Worker Evolution Strategy — Round 1

## 进化目标

降低审计模式下对间接数据流和路径覆盖不足的漏报

## 重点关注

（请根据进化目标补充具体的关注点）
- 关注哪些类型的函数调用
- 关注哪些数据流模式
- 关注哪些漏洞类型

## 检查策略

（请补充具体的检查步骤）
1. 对于网络输入函数，追踪数据流到内存操作
2. 检查 size 参数是否来自用户可控数据
3. 验证边界检查是否存在

## 注意事项

- 不要遗漏间接数据流路径
- 注意类型转换导致的隐式截断
